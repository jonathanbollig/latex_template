## Language
- The thesis is written **entirely in English**.
- The single exception is `frontmatter/abstract_german.tex` (the Zusammenfassung).
  It is plain German text; babel stays `[english]` and there is deliberately no
  language switch for it. Do not add German anywhere else, and do not add babel
  language machinery for this one page.

## Build
- Page numbers are plain arabic and continuous, title page to last page.
  There is deliberately no `\frontmatter`/`\mainmatter`/`\backmatter`;
  do not add them back.
- The document is laid out for **reading on screen**: `oneside,openany`, no
  binding offset, coloured hyperlinks. The print alternatives are commented in
  place in main.tex and preamble.tex. Do not switch to the print layout unless
  I ask.
- Build with `latexmk` from the repo root. Config lives in `.latexmkrc`;
  do not pass engine flags manually.
- Output goes to `build/`. NEVER edit anything under `build/`.
- While drafting a single chapter, set `\includeonly{...}` in main.tex
  to skip the others. Restore the full list before any review build.

## On errors
- Read `build/main.log`. Do not dump the whole file; it is thousands of
  lines. Grep it:
    grep -n -A3 '^!' build/main.log
    grep -n 'Undefined control sequence\|Undefined reference\|Citation.*undefined' build/main.log
- `-file-line-error` means real errors also appear as `file.tex:42: message`,
  so `grep -n -i -A4 'error' build/main.log` catches package errors that
  `^!` misses.
- Fix, rebuild, repeat. If the same error survives two attempts, stop and
  explain the problem rather than trying another workaround.

## Visual inspection
- Do NOT rasterize the whole document. Render only the pages you changed:
    pdftoppm -png -r 110 -f 42 -l 43 build/main.pdf /tmp/pg
- Do inspect visually after: new or resized figures, any table, the title
  page, and anything involving `\begin{align}` blocks longer than three
  lines. Prose edits do not need a visual check.
- `pdfinfo build/main.pdf` for page count.

## Writing conventions
- ONE SENTENCE PER LINE. Never reflow or rewrap existing paragraphs;
  it destroys the git diff.
- Do not rewrite my prose unless I explicitly ask. Fixing a typo I point
  at does not license editing the surrounding sentences.
- First line of every file under `chapters/` and `frontmatter/` is
  `% !TEX root = ../main.tex`. Keep it there; LaTeX Workshop needs it to
  build the whole thesis when a chapter file is the active editor tab.
- All macros live in `macros.tex`. Use the existing ones rather than
  inlining equivalents. Add new ones there, not in chapter files.
- Every number with a unit goes through siunitx: \qty{4.2}{\kelvin},
  \qtyrange{250}{700}{\nano\metre}, \num{1.6e-19}. Never a bare "4.2 K".
- Uncertainties are set with `separate-uncertainty = true`, so
  `\qty{4.2(3)}{\pico\second}` prints as "4.2 ± 0.3 ps".
- Chemical formulas via mhchem: \ce{H2O}, \ce{Mo3S13^2-}.

## Cross-references
- Label prefixes, always: `ch:` `sec:` `fig:` `tab:` `eq:` `app:`.
- Every chapter gets a `\label{ch:...}` directly under its `\chapter{}`.
- Reference with cleveref, never a bare `\ref`: `\cref{fig:setup}` → "fig. 3",
  `\Cref{fig:setup}` → "Fig. 3" at the start of a sentence.

## Figures
- Files go in `figures/`; `\graphicspath` is set, so `\includegraphics{name}`
  without the directory.
- Vector (PDF) for plots, raster only for photographs.
- Every figure gets `\caption{}` then `\label{fig:...}`, in that order —
  a label before the caption picks up the wrong counter.
- The caption carries the explanation; the body text says why the reader
  should look at the figure.

## Citations — strict
- NEVER invent a citation, a DOI, or a bibliography entry.
- Don't edit references.bib. It is maintained by Zotero.
- Citation keys are generated by Zotero (Better BibTeX) and already exist in references.bib. Never construct a key yourself. Check references.bib to find all keys. 
- `\autocite{key}` for a source at the end of a statement, `\textcite{key}`
  when the authors are the sentence subject. Never plain `\cite`.

## Before saying a task is done
1. `latexmk` exits 0
2. no "Citation ... undefined" or "Reference ... undefined" in the log
3. no new Overfull \hbox over 20pt
4. `git diff --stat` shows only files the task should have touched
